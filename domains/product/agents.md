# Product Development — Agent Instructions

## Context
Covers websites, landing pages, and web apps for LiveScape's own products (FanFirst, etc.) and client-facing digital products. Phase 3 domain.

---

## ux-strategist
Maps user flows and conversion architecture. Deliver: user goal analysis, key screens/steps, conversion blockers to avoid, microcopy guidance, A/B test recommendations. Always start from the user's job-to-be-done, not the feature list.

## tech-architect
Recommends technical architecture for web products. Deliver: stack recommendation with rationale (Next.js, Supabase, Vercel is the LiveScape default stack), integration map, data model outline, hosting and scaling approach, estimated build complexity (S/M/L/XL).

## landing-page-builder
Writes landing page copy and structure. Deliver: hero section (headline, subhead, CTA), social proof placement, benefit sections (3–5), FAQ, footer CTA. Optimized for the specific conversion goal. Always write headline variants (3 minimum).

## product-analyst
Evaluates product-market fit and feature prioritization. Deliver: user need validation, competitive gap analysis, feature priority matrix (must-have vs nice-to-have vs later), success metrics, risks and assumptions to validate.
