# LiveScapeOS — Copy-Paste Prompts for Colleagues

Use these prompts in Claude Code to set up and work with LiveScapeOS. Colleagues just copy, paste, and hit enter.

---

## Setup (One-Time)

### Prompt 1: Install Ruflo
```
I'm setting up Ruflo for collaborative P&L work. Install the Ruflo MCP into my Claude system, then verify it's working by checking the daemon status.
```

### Prompt 2: Clone & Configure
```
Clone the LiveScapeOS repository from https://github.com/iqbalaaameer/LiveScapeOS into my working directory. Set up GitHub authentication (gh auth login), then verify the Ruflo configuration in .claude/settings.json is active.
```

---

## Work (Repeatable)

### Prompt 3: Generate Your First P&L
```
I need a P&L for a classical concert at a mid-sized venue (500 capacity, $75 avg ticket price). Use the patterns from the shared memory to generate it.
```

### Prompt 4: Generate Any P&L (Template)
```
I need a P&L for [CONCERT TYPE] at [VENUE SIZE] with [TICKET PRICE] pricing. Load all previous concert patterns from shared memory, spawn the agent team, and generate it.
```

**Example filled in:**
```
I need a P&L for an EDM festival at a large outdoor venue (5000 capacity, $120 avg ticket price). Load all previous concert patterns from shared memory, spawn the agent team, and generate it.
```

---

## After Each Work Session

### Prompt 5: Sync Learnings to GitHub
```
Commit and push all my P&L learnings from this session to the shared LiveScapeOS repository on GitHub so my colleagues can benefit from them. Use "chore: sync pnl learnings" as the commit message.
```

---

## Workflow Summary

1. **First time:** Run Prompts 1 → 2
2. **Every P&L:** Run Prompt 4 (fill in concert type, venue, price)
3. **End of session:** Run Prompt 5

That's it. Agents handle the rest.
